# Portfolio (PT-BR)

## Sobre o Projeto

Este é o meu **portfólio pessoal**, criado com **React, Vite e Tailwind CSS**, para exibir meus **projetos, habilidades técnicas e artigos** de forma moderna e interativa.

Ele serve para mostrar meu **trabalho como desenvolvedor**, com foco em **back-end, projetos completos e boas práticas de desenvolvimento**.

🌐 **Acesse:** [kelvinlemosportfolio.vercel.app](https://kelvinlemosportfolio.vercel.app/)

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia       | Finalidade                                  |
| ---------------- | ------------------------------------------- |
| React            | Componentes reutilizáveis e interatividade  |
| Vite             | Bundler rápido para desenvolvimento moderno |
| Tailwind CSS     | Estilização utilitária responsiva           |
| Framer Motion    | Animações e transições suaves               |
| React Router     | Navegação entre páginas                     |
| React Query      | Gerenciamento de dados e cache              |
| Formspree        | Formulário de contato funcional             |
| Git/GitHub       | Versionamento de código                     |

## 📁 Estrutura do Projeto

```
portfolio-app/
├─ public/                # Assets públicos (imagens, ícones)
├─ src/
│  ├─ assets/             # Imagens do portfolio (me.png, kelvin.jpeg, etc)
│  ├─ components/         # Componentes reutilizáveis
│  │  ├─ portfolio-app/   # Componentes específicos do portfolio
│  │  └─ ui/              # Botões, Inputs, Cards, etc
│  ├─ hooks/              # Hooks customizados (ex: use-mobile.jsx)
│  ├─ lib/                # Funções utilitárias (utils.js, index.ts)
│  ├─ App.jsx             # Componente principal
│  ├─ Layout.jsx          # Layout geral do site
│  ├─ main.jsx            # Entrada da aplicação (Vite)
│  ├─ index.css           # Estilos globais
│  └─ App.css             # Estilos específicos do App
├─ .gitignore
├─ package.json
├─ tailwind.config.js
├─ postcss.config.js
├─ vite.config.js
└─ README.md
```
